# Jackson Kimotho | Portfolio

Welcome to the data scientist and AI engineering portfolio for **Jackson Kimotho**. 

This repository contains the source code for a sleek, highly-optimized single-page web application. It features customized CSS-variable dark/light theming, robust layout designs for project highlights, and integrated contact form routing.

### 🚀 Tech Stack
- **React 19**
- **TypeScript**
- **Vite**
- **Tailwind CSS (v4)**
- **Motion (Framer Motion)**
- **Lucide Icons**

### 💻 Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server locally:
   ```bash
   npm run dev
   ```
